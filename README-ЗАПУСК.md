# Сайт сервиса Genesis АВИЛОН — локальный запуск

## Что нужно

- **Node.js 22 LTS** — https://nodejs.org (при установке все галочки по умолчанию).
- Интернет при первом запуске (скачиваются зависимости, ~200 МБ).

## Windows — проще всего

1. Распакуйте архив в любую папку (лучше без кириллицы и пробелов в пути, например `C:\avilon-site`).
2. Дважды кликните **`ЗАПУСК.bat`**.
3. Первый раз установятся зависимости (1–2 минуты), потом откроется браузер на http://localhost:8080.
4. Чтобы остановить сайт — закройте чёрное окно.

## Вручную (Windows / macOS / Linux)

```bash
npm install
npm run dev
```

Затем откройте http://localhost:8080

## Где что лежит

| Что поменять | Файл |
|---|---|
| Тексты, спецпредложения, услуги, FAQ, телефоны, адрес | `src/data/site.ts` |
| Главный экран | `src/components/landing/hero.tsx` |
| Шапка | `src/components/landing/header.tsx` |
| Спецпредложения, услуги, фото, преимущества | `src/components/landing/work.tsx` |
| Отзывы и FAQ | `src/components/landing/trust.tsx` |
| Форма заявки и футер | `src/components/landing/visit.tsx` |
| Кнопка | `src/components/ui/arrow-fill-button.tsx` |
| Цвета и стили | `src/styles.css` |
| Картинки и иконки | `public/images`, `public/icons` |

Изменения в файлах подхватываются в браузере сразу, перезапускать не нужно.

## Важно

- Картинки большинства спецпредложений и часть 3D-иконок услуг подгружаются из интернета
  (genesis-avilon.ru и cdn.jsdelivr.net). Без интернета они не покажутся.
- Форма заявки пока открывает письмо в почтовой программе — на сервер заявки не отправляются.
